How Duties Are Calculated

  1. Customs Duty based on CIF value and HS code classification.
  2. SCT where applicable for vehicles, fuel, alcohol, or other select goods.
  3. Environmental Levy and Stamp Duty where relevant.
  4. GCT on CIF plus applicable charges.

Use this as a quote starter. Exact landed cost still depends on classification, permits, and valuation review.
